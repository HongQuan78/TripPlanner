## Deferred from: code review of story 9-1-dockerize-for-production (2026-07-17)

- Base image tags unpinned/floating (`nginx:alpine`, `postgres:16`, `node:22-alpine`, `mcr.microsoft.com/dotnet/*:10.0`) — not digest-pinned, so image builds are not reproducible across time. Optional hardening. [BE/Dockerfile, FE/Dockerfile, docker-compose.yml]
- Required secrets use bare `${VAR}` substitution with no `${VAR:?message}` fail-fast guard. A missing host `.env` key substitutes an empty string with only a warning; empty `JwtSettings__SecretKey` yields an invalid signing key and empty int `EmailSettings__TokenExpiryHours` fails option binding at startup — late and cryptic rather than an early clear error. [docker-compose.yml]
- `Cache-Control: public, immutable` with `expires 30d` is applied to non-content-hashed static assets (`favicon.ico` and other `public/` images keep stable names), so clients won't pick up a changed asset for 30 days without a hard refresh. Vite-hashed JS/CSS is safe; the raster/icon extensions are not. [FE/nginx.conf]
- No `proxy_read_timeout`/`proxy_connect_timeout` on the `/api/` proxy. Endpoints backed by the external OpenTripMap/Wikipedia calls that exceed nginx's default 60s produce a 504 while the upstream is still working. [FE/nginx.conf]
